# Setlists

La setlist reste interne : les six membres de l’équipe peuvent la lire. **Seuls Julien, Rémi, Franck et Sylou peuvent la modifier.** Elle n’apparaît ni dans l’espace salle, ni dans les invitations, ni dans les PDF techniques.

## Préparer la référence

Dans **Fiche technique**, ouvrir le petit encart **Setlist**, puis **Créer la setlist** ou **Modifier**. Saisir un morceau par ligne, dans l’ordre de passage, puis enregistrer. Les lignes vides sont ignorées ; vider le champ retire tous les titres.

## Préparer un concert

Dans le dossier du concert, ouvrir **Setlist** :

- **Importer la référence** copie les titres du groupe après un aperçu. Si le concert possède déjà une setlist, confirmer son remplacement.
- **Créer la setlist / Modifier** permet de saisir une version propre à cette date.

Un nouveau concert commence sans setlist. L’import est volontaire : modifier ensuite la référence ne change pas les concerts déjà préparés, et modifier un concert ne change pas la référence.

Si quelqu’un a enregistré une modification pendant la saisie, l’application demande de recharger. Les titres saisis restent affichés pour pouvoir les recopier avant de reprendre.
