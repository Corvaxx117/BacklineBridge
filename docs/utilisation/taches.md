# To Do du groupe

Cet espace rassemble les missions du groupe, indépendamment des concerts : merch, communication, répétitions, administration…

## Créer et répartir

Ouvrir **To Do → Nouvelle tâche**. Donner un titre, puis ajouter si utile des précisions, un responsable et une date. Une tâche peut rester non attribuée. Un profil peut recevoir une tâche avant sa première connexion.

Le tableau est partagé : les changements sont visibles par les autres membres lorsqu’ils rechargent la page. **Mes tâches** affiche celles attribuées à son propre profil ; **Non attribuées** aide à répartir le travail.

## Faire avancer

**Commencer** passe une tâche en cours ; **Terminer** la marque accomplie. **Réouvrir** la remet à faire. Les dates dépassées sont signalées, sauf pour les tâches terminées. Les échéances proches apparaissent en premier dans chaque colonne.

**Modifier** permet de changer le responsable, les précisions, la date ou l’état. Si quelqu’un a modifié la tâche depuis l’ouverture du formulaire, un message demande de recharger plutôt que d’écraser sa saisie.

## Accès

Les musiciens, Marty et Romain peuvent créer, attribuer et modifier les tâches. Un responsable peut supprimer toute tâche ; les autres collaborateurs peuvent supprimer celles qu’ils ont créées. Une confirmation est demandée. Les éventuels comptes en lecture seule peuvent consulter le tableau. Les régisseurs invités n’y ont pas accès.

Il n’y a pas encore de notification automatique ni de synchronisation en temps réel.
