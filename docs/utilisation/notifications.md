# Notifications du groupe

La cloche de l’en-tête ouvre les nouveautés de votre équipe. Le compteur indique vos notifications non lues et s’actualise à la minute quand l’onglet est visible, ainsi qu’à votre retour sur la page.

## Événements suivis

- Création d’un concert : auteur, date de l’action et concert concerné.
- Import Bandsintown : une seule notification pour tout le lot, avec le nombre de concerts ajoutés ou rattachés. Les annonces ignorées ne produisent rien.
- Ajout d’un document PDF ou d’un lien, dans la bibliothèque ou dans un concert.
- Ajout d’une feuille de route : une notification dédiée, sans doublon « document ajouté ».

Les nouvelles actions sont enregistrées à partir de la mise en place de cette fonction. L’historique antérieur n’est pas repris.

## Lire et consulter

**Consulter** ouvre le concert ou le document concerné et marque la notification comme lue. Vous pouvez aussi changer sa lecture individuellement, filtrer les non lues ou choisir **Tout marquer comme lu**. Ce choix est personnel : il ne change pas les compteurs des autres membres.

Vos propres actions apparaissent déjà lues. L’auteur et la date d’origine restent conservés ; un élément supprimé apparaît comme retiré, sans lien cassé. Les dates s’affichent dans le fuseau Europe/Paris.

Seules les notifications des groupes dont vous êtes encore membre sont visibles. Les régisseurs invités ne voient pas cet historique.

## Activer les push

Sur le site officiel, ouvrir la cloche, déplier **Notifications sur cet appareil**, puis choisir **Activer sur cet appareil** et accepter la demande du navigateur. Le bouton **Envoyer un test** vérifie uniquement cet appareil.

Sur iPhone, ouvrir le site dans Safari, choisir **Partager → Sur l’écran d’accueil**, puis ouvrir cette icône et se connecter avant l’activation. Sur ordinateur ou Android compatible, l’activation se fait depuis le navigateur.

Le choix se fait sur chaque appareil. Tant que l’autorisation reste accordée et que vous ne vous déconnectez pas, il n’est pas nécessaire de le répéter. Une déconnexion désactive les push de cet appareil ; après reconnexion, un clic permet de les réactiver, sans nouvelle demande système si l’autorisation existe encore. Un changement de mot de passe révoque aussi les appareils du compte ; chacun doit alors être réactivé.

## Qui reçoit quoi ?

Une nouvelle action est partagée avec les membres actuels du groupe. Les régisseurs invités sont exclus. Les push partent uniquement vers les appareils que ces personnes ont activés. L’auteur garde sa trace dans la cloche, déjà lue, sans recevoir de push pour sa propre action.

L’association repose sur l’identifiant du compte dans BacklineBridge et sur un abonnement propre au navigateur. Ni numéro de téléphone ni inscription à un service externe ne sont nécessaires. Un compte peut activer plusieurs appareils.

Le texte peut apparaître sur l’écran verrouillé : chacun peut régler l’affichage des aperçus sur son appareil. Les informations administratives, les soldes et les stocks ne sont pas inclus dans les push de cette version.
