# Agenda du groupe

L’onglet **Agenda** présente les événements de l’agenda Google **Avee Mana Partagé** dans un calendrier. Les six membres de l’équipe — Julien, Rémi, Franck, Sylou, Marty et Romain — peuvent le consulter. Les invités de salle n’y ont pas accès. Cela ne change pas les droits déjà accordés directement dans Google.

## Consulter

Ouvrir **Agenda**, puis choisir **Mois**, **Semaine** ou **Liste**. Les flèches changent la période ; **Aujourd’hui** ramène à la date actuelle.

Cliquer sur un événement pour voir son titre, son horaire et son lieu. **Ouvrir dans Google Agenda** permet ensuite de le modifier avec son compte Google habituel. Les répétitions récurrentes, journées entières et événements sur plusieurs jours sont conservés.

Sur téléphone, la vue Semaine se fait défiler horizontalement ; la vue Liste donne une lecture sur une seule colonne. **Consulter la liste simple** reste disponible, même si JavaScript est désactivé.

Les changements faits dans Google apparaissent sous cinq minutes. Le calendrier affiche toujours le fuseau du groupe, même si le navigateur est réglé sur un autre fuseau.

## Ajouter un concert

Les quatre musiciens peuvent utiliser **Ajouter à Google Agenda** dans le dossier d’un concert. Marty et Romain peuvent consulter l’agenda ; ce changement ne leur donne pas le droit d’y publier depuis BacklineBridge. Cela fonctionne pour un concert créé à la main ou importé de Bandsintown.

- L’heure renseignée dans le concert est utilisée ; sans horaire, le début est fixé à **20 h**.
- La durée proposée est de **1 heure**, ajustable ensuite dans Google.
- Le titre indique le groupe et la salle. Une date non validée porte la mention **En attente**.
- Seuls le titre, le lieu et les horaires sont envoyés. Aucun document, contact, montant ou note du dossier n’est publié.
- Un deuxième clic retrouve l’événement déjà ajouté, sans créer de doublon ni remplacer les modifications faites dans Google.

Les ajouts sont volontaires. Modifier ou supprimer ensuite le dossier dans BacklineBridge ne modifie pas l’événement Google. Corriger aussi Google lorsque la date, le statut ou le lieu change. Un événement déjà saisi à la main dans Google reste distinct : le bouton ne le reconnaît pas automatiquement.

Les horaires utilisent le fuseau configuré pour le groupe, initialement **Europe/Paris**. Pour un concert dans un autre fuseau, vérifier l’horaire dans Google après l’ajout.

## Si l’agenda est indisponible

Une erreur Google n’efface ni ne modifie le concert. Attendre puis réessayer. Après une coupure pendant l’ajout, le bouton peut retrouver l’événement déjà créé.

Si un événement ajouté par BacklineBridge a été supprimé dans Google, vérifier l’agenda avant de le recréer manuellement : le bouton ne restaure pas les événements supprimés.

La connexion est configurée une fois pour le groupe ; aucun raccordement des agendas personnels n’est nécessaire. Voir [Connecter Google Agenda](../exploitation/google-agenda.md).
